# Gem Slide

A gothic match-3 battle game for Android. Slide gems, fill buckets, strip the enemy's armour
before he falls.

Play the latest build: https://gothicmatchr.github.io/Gothic-Match-R/

Project notes, rules and standards: see [CLAUDE.md](CLAUDE.md).
